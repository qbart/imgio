# Basis Universal

Public: `imgio::basis`. Internal low-level transcoder: `src/basis/ll` (ported from ktx-rs
`src/basisu`, which ports basisu's transcoder: ETC1S, UASTC LDR 4x4, UASTC HDR 4x4,
ASTC HDR 6x6, UASTC HDR 6x6 intermediate; targets 0-27 of `transcoder_texture_format`).
basisu v2 tex formats 5..33 are parsed (`XuastcLdr(block)` 5..18, `AstcLdr(block)` 19..32 in
basisu block order 4x4, 5x4, 5x5, 6x5, 6x6, 8x5, 8x6, 10x5, 10x6, 8x8, 10x8, 10x10, 12x10, 12x12;
`Xubc7` 33); their transcoders are being ported from C++ basisu (no ktx-rs groundwork).

## .basis container (`BasisFile`)

- Layout from `basisu_file_headers.h`: 77-byte header, 23-byte slice descriptors, packed LE.
- Validation: signature `sB`, version 0x13, header size, header CRC16 (bytes 8..77), data CRC16,
  slice/image counts, ETC1S flag consistency (even slice count with alpha), every section and
  slice in bounds, slice block counts match its size.
- Header flag 16 (`cBASISHeaderFlagSRGB`): ASTC sRGB decode profile (`is_srgb`).
- Lookup: `level_count(image)`, `level_info(image, level)`; ETC1S alpha slices are the ones with
  `cSliceDescFlagsHasAlpha`.

Test data `testdata/basis/*.basis`: encoded by Basis Universal v2.50 (C++ CLI built from
`ref/basisu`) from `testdata/images` (generated by `scripts/gen_images.py`) with
`scripts/gen_basis_testdata.sh` (commands for every file).

## Transcoding (`BasisFile::transcode`)

- `transcode(image, level, format, dst)`, `transcode_to_buffer`, `transcoded_size`,
  `can_transcode_to`. Output is tightly packed blocks/pixels of `format` for the level size.
- `transcode_with` / `transcode_to_buffer_with` take `TranscodeOptions` = basisu decode flags
  (`flags()` / `from_flags()`; `Default` = flags 0): `high_quality` (32), `alpha_to_opaque` (4),
  `bc1_forbid_three_color` (8), `etc1s_chroma_filtering` (off = 64), `deblock`
  `Auto`/`Off`/`Force` (128 / 512; `Auto` = container rule), `xuastc_fast_bc7` (off = 1024).
  ETC1S / UASTC / HDR get the raw flags (ported low-level transcoders). ASTC LDR / XUASTC /
  XUBC7 map them to `astc_ldr::BlockOpts` like C++ `transcode_4x4_block`: high quality = HQ
  EAC (`pack_eac_high_quality`), HQ BC1, partially analytical `bc7f` (BC7, XUBC7 -> ASTC);
  alpha to opaque (needs container alpha) = ETC1 via `pack_etc1_grayscale(A)`, BC4 / R11 from
  A, PVRTC1 RGB on gray alpha. XUASTC 6x6 / 8x6 -> BC7 fast paths need fast on and not high
  quality; 4x4 always packs solid blocks to mode 5, its mode 6 shortcut needs the same.
- Targets map to basisu `transcoder_texture_format` (sRGB variants share the unorm target):
  ETC1, ETC2 RGBA, BC1/3/4/5/7, PVRTC1/2, ASTC 4x4 LDR/HDR, ATC, RGBA32, 565, 4444, EAC
  R11/RG11, BC6H, RGB/RGBA half, RGB9E5, ASTC 6x6 HDR, FXT1 (`Format::Fxt1Rgb`, 8x4 blocks).
- FXT1 (ETC1S only, as in C++): `ll/fxt1.rs`, port of `convert_etc1s_to_fxt1`. Each ETC1S
  block goes to BC1, then to one CC_MIXED half of an 8x4 block (565 -> 555 + green LSB,
  remapped selectors); the left half writes the whole block, the right half overwrites its
  colors/selectors. UASTC / ASTC LDR / XUASTC / XUBC7 -> FXT1 is unsupported in C++ too.
- ASTC HDR 6x6 sources: `ll/astc_hdr_6x6.rs`, ported from C++
  `basisu_lowlevel_astc_hdr_6x6_transcoder`; shares the output stage
  (`transcode_astc_6x6_blocks`) with the 6x6 intermediate transcoder.
- ETC1S codebooks/Huffman tables decoded once per file (`OnceLock`).
- ASTC LDR (and XUASTC once decompressed): `basis/astc_ldr.rs`, after C++
  `basisu_lowlevel_xuastc_ldr_transcoder::transcode_slice`. Same-size ASTC target = copy.
  Other targets: blocks decoded (`astc_helpers`, sRGB8 or LDR8 profile from header flag 16 /
  vkFormat parity; invalid block = `InvalidData`) into a padded RGBA8 image, rows of blocks in
  parallel, then emitted per 4x4 block (x clamped to padded width; y clamped to the image
  height, or to the padded height on the C++ whole-image path: deblocking / PVRTC1).
  Uncompressed: RGBA32 copy; 565/4444 via basisu `mul_8`. 4x4 sources need no clamping.
  Block targets (`transcode_4x4_block`, default channels R and R+A): BC1 (`encode_bc1`), BC3
  (`encode_bc4` alpha + BC1), BC4 (R), BC5 (R, A), EAC R11 (R) / RG11 (R, A) via `pack_eac`; ETC1 via `ll/etc1f.rs` (port of C++
  `etc1f`; its `pack_etc1_state` is only a solid-block memo and is omitted) and ETC2 RGBA (EAC
  alpha + ETC1); BC7 via `ll/bc7f.rs` (port of C++ `bc7f`, default flags); block rows in parallel.
- Deblocking: `.basis` deblocks blocks of >= 80 texels (basisu default); KTX2 deblocks iff key
  `DeblockFilterID` = "1". `basis/deblock.rs` ports `xuastc_deblock_filter` (corner 5-tap in
  f32 / 6, edge 3-tap integer averages, interior copy; rows in parallel); applied to the padded
  decoded image before any non-ASTC target.
- PVRTC1 (power-of-two sizes only): `basis/pvrtc1_enc.rs` ports `encode_pvrtc1` (per-block
  min/max endpoints, floor/ceil quantized; modulation via the shared
  `ll::pvrtc::fixup_pvrtc1_4_modulation`).
- XUBC7: `basis/xubc7/` after C++ `basisu_lowlevel_xubc7_transcoder::transcode_slice`.
  `decoder.rs` ports `basisu_xbc7_decoder.{h,inl}`: blob container (0xB7, LEB128 sizes, zstd
  blobs via `ruzstd` into one arena), tiny-mip streams (0xB8/0xB9: raw BC7), per-stripe seek
  table; stripes decoded in parallel (references never leave a stripe). Per block: commands
  (repeat, solid DPCM, new/reused config), endpoints raw or DPCM (`ll/bc7u.rs`, integer
  `pack_endpoints_int`), weights raw/DPCM or fixed point Q15.16 4x4 DCT with 17 synthetic + 32
  block-copy predictors and amplitude codes. Malformed streams are `InvalidData`.
  Targets from the logical blocks (`ll/bc7u.rs`): BC7 = `pack_bc7`; ASTC 4x4 =
  `ll/bc7f_astc.rs` (`bc7f::fast_pack_astc` latent to latent, unmappable 2/3-subset patterns
  re-encoded with `bc7f` in ASTC compatible mode; includes the `astc_ldr_t` base+scale /
  base+offset conversions); others decode to a padded RGBA8 image and reuse the ASTC LDR 4x4
  output stage (stream `has_alpha` only matters for the C++ BC7 path, never taken). PVRTC1
  RGBA falls back to RGB without the container alpha flag.
  `DeblockFilterID` = "1".
- XUASTC LDR: `basis/xuastc/` decompresses a slice to ASTC logical blocks (port of
  `astc_ldr_t::xuastc_ldr_decompress_image[_full_zstd]`): syntax byte 0 = full arithmetic
  (`arith.rs`, basisu range coder + adaptive models), 1 = hybrid (arithmetic + Zstd weight
  streams), 2 = full Zstd (byte/bit streams, `ruzstd`). Shared: trial mode tables from
  `basisu_astc_cfgs.inl` (lazily per block size), unique partition pattern -> seed tables,
  endpoint DPCM via `convert_endpoints_across_cems` (`endpoints.rs`, integer only), weight
  DPCM, DCT weight grids (`dct.rs`: deadzone dequant, JPEG-derived adaptive quant table,
  `basisu_idct.h` IDCT; f32 in C++ operation order). Every block is kept (the C++ 8 row ring
  only holds past blocks, which is all a stream may reference). The stream header's block size
  and block counts must match the container (checked before allocating); its sRGB decode
  profile and alpha flag are used instead of the container's. Then the ASTC LDR pipeline above
  runs on the logical blocks (ASTC target: `pack_astc_block`; others: `decode_block`, equal to
  C++ `decode_block_xuastc_ldr`). Corrupt streams return `InvalidData`.
- XUASTC -> BC7 fast paths (`basis/xuastc_bc7.rs`, `ll/bc7f_xuastc.rs` = `bc7f::pack_from_astc_*`),
  logical blocks only (plain ASTC LDR keeps the pixel path), block 4x4 / 6x6 / 8x6, no
  deblocking; default decode flags (fast BC7 on, not high quality). 4x4: solid -> mode 5,
  1 subset single plane -> mode 6 from ASTC endpoints + upsampled weights (`(w*15+32)>>6`),
  else decode + `fast_pack_bc7_auto_rgb[a]` (stream `has_alpha`). 8x6: tiles of 1x2 ASTC
  blocks -> 2x3 BC7; 6x6: 2x2 ASTC blocks -> 3x3 BC7, center block last. Per BC7 block: inside
  one simple block (mode 5 / mode 6), straddling two with equal solid colors (6x6) or equal
  endpoints (tol 0 for 8x6, 1 for 6x6: averaged endpoints, mode 6), two opaque different
  blocks (mode 1, part 13 or 0; 8x6 uses the `_hq` variant: endpoints refit to the used weight
  range via `channel_interpolate`, both subsets low contrast -> decoded texels +
  `fast_pack_bc7_rgb_analytical`), otherwise decode + analytical encode. Edge tiles duplicate
  the last ASTC column / row (C++ pointer clamping), not pixel clamping. Row pairs of ASTC
  blocks (3 BC7 rows each) run in parallel. The non-`_hq` 8x6 packer is unreachable with
  default flags and not ported.
- UASTC 4x4 (LDR/HDR): one row of source blocks per work unit, multithreaded through
  `parallel::for_each_unit` (PVRTC1 transcodes the whole image at once; ETC1S is sequential).
- Golden test: `tests/basis_transcode.rs` vs `testdata/basis/golden.txt`, FNV-1a hashes of every
  level x supported target from the C++ transcoder (`tools/basisu-golden/dump.cpp`, offline
  dev tool, not part of the crate; targets 0..40). PVRTC1 on non-power-of-two sizes fails in
  both. `golden_flags.txt` (`dump -f N`): selected files with decode flags 4, 8, 32, 64, 128,
  512, 1024, 1056 (`decode_flags` tests).
