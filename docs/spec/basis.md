# Basis Universal

Public: `imgio::basis`. Internal low-level transcoder: `src/basis/ll` (ported from ktx-rs
`src/basisu`, which ports basisu's transcoder: ETC1S, UASTC LDR 4x4, UASTC HDR 4x4,
ASTC HDR 6x6, UASTC HDR 6x6 intermediate; targets 0-27 of `transcoder_texture_format`).
XUASTC / ASTC LDR (basisu v2.x tex formats 5+) are not covered yet.

## .basis container (`BasisFile`)

- Layout from `basisu_file_headers.h`: 77-byte header, 23-byte slice descriptors, packed LE.
- Validation: signature `sB`, version 0x13, header size, header CRC16 (bytes 8..77), data CRC16,
  slice/image counts, ETC1S flag consistency (even slice count with alpha), every section and
  slice in bounds, slice block counts match its size.
- Lookup: `level_count(image)`, `level_info(image, level)`; ETC1S alpha slices are the ones with
  `cSliceDescFlagsHasAlpha`.

Test data `testdata/basis/*.basis`: encoded by Basis Universal v2.50 (C++ CLI built from
`ref/basisu`) from `testdata/images` (generated by `scripts/gen_images.py`).
