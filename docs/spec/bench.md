# Benchmarks

`make bench` (`benches/bench.rs`, no external harness): best of N runs, Mpix/s.
Decode on 1024x1024 random blocks (ASTC: tiled encoded blocks); transcode on 512x512 KTX2 files
in `testdata/bench` (from `testdata/images/bench_512.png`, regenerated by `scripts/gen_images.py`;
`etc1s_cube_512.ktx2` by `scripts/gen_basis_testdata.sh`).

Snapshot 2026-11-21 (Linux x86-64, release; C++ = basisu v2.50 transcoder, single thread, -O2):

| transcode 512x512 | imgio | C++ |
|---|---|---|
| ETC1S -> BC7 | 6.5 ms | 6.9 ms |
| ETC1S -> BC1 | 0.52 ms | 0.63 ms |
| UASTC -> BC7 | 0.43 ms | 2.12 ms |
| UASTC -> BC1 | 0.64 ms | 2.89 ms |
| UASTC -> ASTC 4x4 | 0.35 ms | 1.14 ms |

| transcode_all, ETC1S cube 512 + mips (6 x 10 images) | one by one | `transcode_all` |
|---|---|---|
| -> BC7 | 46.4 ms | 10.6 ms |
| -> BC1 | 3.9 ms | 0.96 ms |

ETC1S slices decode sequentially (predictive coding), so they run on one thread; UASTC 4x4 is
split into rows of blocks. Parallel work starts at 64K pixels.

| encode 1024x1024 (tiled smooth image) | imgio |
|---|---|
| BC1 fast / high | 1.3 ms / 1.8 ms |
| BC3 | 1.8 ms |
| BC5 | 0.8 ms |
| BC7 fastest / default (bc7f) | 2.2 / 7.8 ms |
| BC7 high / best (bc7e slow / slowest) | 139 / 797 ms |
| BC6H default | 5.0 ms |
| ETC1 / ETC2 RGBA (HQ EAC) | 1.3 / 9.8 ms |
| ASTC 4x4 fast / medium, 8x8 medium (astcenc) | 107 / 204 / 247 ms |
