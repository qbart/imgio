# Image file formats (`imgio::file`)

Shared API (every format module follows it):

- `FileFormat` (14 formats), `FileFormat::detect(bytes)` (signatures; TGA last by footer /
  header heuristics), `extension`, `from_extension`.
- `Image { format, width, height, data: Buffer }` (owned, tightly packed), `surface()`,
  `from_surface`, `with_format` (relabel, e.g. sRGB -> unorm).
- `Frame { image, delay: (num, den) }`, `Animation { frames, loops }` (0 = forever).
- `decode(bytes)` / `decode_as(fmt, bytes)`: main image; `decode_animation(bytes)`: all frames
  (GIF / APNG / WebP / JPEG XL, still otherwise); `encode(fmt, &Surface)`: default options.
- Per format module `imgio::file::<fmt>`: `decode`, `encode(&Surface, &EncodeOptions)`,
  (`decode_animation`), plus format-specific APIs (EXR layers, TIFF pages, VDB grids, ...).
- Decoded pixel formats: 8-bit gray `R8Unorm`, gray+alpha `Rg8Unorm`, RGB `Rgb8Srgb`, RGBA
  `Rgba8Srgb`; 16-bit `R16Unorm` / `Rg16Unorm` / `Rgba16Unorm`; half `Rgb16Float` /
  `Rgba16Float`; `Rgba32Float`. Palette / sub-byte / packed samples expand to 8 bits.
  Animation frames are composited, canvas-sized.
- Crate-backed formats are cargo features (`png`, `gif`, `webp`, `jpeg`, `exr`, `tiff`,
  `jxl`, `jpeg2000`, `vdb`, `avif`; default `png` + `jpeg`); only pure Rust crates (no `-sys`,
  no `cc` / C build dependencies in the tree). BMP, TGA, HDR, zfile: own code, always on.
- Test files: generated by `scripts/gen_file_testdata.py` (offline reference encoders: ffmpeg,
  Pillow, imagecodecs, OpenEXR in a scratch venv; never linked), stored in `testdata/file/`.
