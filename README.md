# imgio

Pure Rust image and GPU texture codecs: BC1-BC7, ASTC, UASTC, Basis Universal
transcoding, RGBA and HDR variants, later PNG/TGA/JPG. No C/C++ bindings.

Status: early development, see [ROADMAP.md](ROADMAP.md).
